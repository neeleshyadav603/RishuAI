## Rishu v0.4.1 — Windows showcase build

**Download:** `RishuSetup-0.4.1.exe` (below, under Assets). Python or anything else does not need to be installed: everything Rishu needs is inside the installer.

### Install (2 minutes)
1. Download `RishuSetup-0.4.1.exe` and double-click it.
2. Windows may show **"Windows protected your PC" / Unknown publisher**, because the installer is not code-signed yet. Click **More info → Run anyway**.
3. Finish the installer. Rishu opens by itself (also in the Start menu as "Rishu").
4. First start can take 10–30 seconds while Windows Defender scans the new files.

### First-time setup inside the app
- Your name, language (हिंदी / Hinglish / English) and Rishu's voice (male / female, with a preview).
- A **free Groq API key** (console.groq.com → Create API Key). It powers both thinking and listening. The key is stored encrypted on this PC only.
- No key? Choose "offline mode": basic commands still work (open apps, time, notes).

### What works in this build
- Talk by voice: mic button, **Ctrl+Space** inside the app, or **Ctrl+Shift+Space** from any app. Rishu stops listening when you pause, and answers aloud in a natural Hindi or Indian-English voice.
- Chat in Hindi, Hinglish or English with live, streaming replies.
- Opens apps and websites: "Chrome kholo", "notepad kholo", "gitm.edu.in kholo".
- Web search with sources: "Aaj ki AI news search karo".
- Teaching: "Mujhe quantum computing padhao" — ask follow-up and cross questions.
- Notes and time: "Note likho: kal 10 baje meeting", "Mere notes dikhao", "Time kya hua hai?".
- **New in 0.4.1:** your notes, memories and reminders are now stored **encrypted** on this PC (Windows DPAPI, tied to your Windows account). Older files are converted automatically.
- **New in 0.4.0:** **conversation mode** (Settings → Awaaz → Baat-cheet mode): after Rishu answers aloud, the mic opens again by itself, so you can keep talking without pressing anything; say "bas" or "thank you" to end. Off by default; keep it off in noisy rooms.
- **Also new in 0.4.0:** lock Rishu with a PIN, then unlock with the PIN, **Windows Hello** (fingerprint / face / Windows PIN) or a **spoken password**. Say **"Rishu lock"** to lock at once; it also locks after 10 idle minutes. While locked Rishu shows nothing, does nothing, and only says that a reminder is due. Settings → Suraksha (Security).
- **Also new in 0.4.0:** Rishu greets you aloud when it opens; softer speech on built-in laptop mics is heard; if Windows blocks the microphone (privacy switch) or the mic is muted, Rishu says exactly which setting to turn on.
- **New in 0.3.0:** Rishu can look at your screen: "Screen par kya hai, samjhao" or "Yeh error kya hai?" (a smaller screenshot goes to a free Groq vision model).
- **New in 0.2.1:** steadier on the free Groq tier (if one model hits its per-minute limit or fails a tool call, Rishu switches to the next model instead of going offline); better step-by-step teaching; emoji are not read aloud.
- **New in 0.2.0:**
  - YouTube and Google in the browser: "YouTube pe Kesariya chalao", "Google pe GITM admission search karo".
  - Message drafts through official links (you press Send): "WhatsApp pe likho: main 10 minute late hoon", "HOD ko leave ka email draft karo".
  - Computer controls: "awaaz badhao / kam karo / mute karo", "screenshot lo", "computer lock karo" (asks first), "battery kitni hai".
  - Reminders and timers, shown and spoken aloud: "1 minute baad paani peene ka reminder lagao".
  - Memory: "Yaad rakho: mera favourite subject DAA hai" — used in later chats; "kya yaad hai?", "woh bhool jao".
  - Weather: "Gurugram ka mausam batao".
- Permission cards before important actions, a STOP button (or Esc) at any time, and an activity log of everything Rishu did.

### Known limits
- Natural voices need the internet; offline, Windows' own voice is used (Hindi script needs the Windows Hindi speech pack).
- Not in this build yet: two-factor approval for the highest-risk actions (they are refused), camera face unlock without Windows Hello, sending WhatsApp messages automatically, teach mode, self-update, Android app.
