## Rishu v0.7.0 — works on its own: offline brain inside, phone without the laptop, everyday work

**Download:** `RishuSetup-0.7.0.exe` (Windows) and the `.apk` (Android), below under Assets.

### Install on Windows (2–3 minutes)
1. Download `RishuSetup-0.7.0.exe` (about 0.5 GB: the offline brain is inside) and double-click it.
2. Windows may show **"Windows protected your PC" / Unknown publisher** because the installer is not code-signed yet. Click **More info → Run anyway**.
3. Finish the installer. Rishu opens by itself (also in the Start menu as "Rishu"). The first start can take up to a minute while Windows Defender scans the new files.
4. Optional but recommended: add a **free Groq key** in the first-time setup (console.groq.com → Create API Key). With the key Rishu is fast and does the big tasks; without it the offline brain does the simple ones.

### Install on Android
1. Download the `.apk` on the phone, open it and allow installing from this source. If an older Rishu is installed, uninstall it first (the APK is not signed with a permanent key yet).
2. Choose one:
   - **Laptop se jodo:** laptop Rishu → Settings → Phone se jodo → code; type the code on the phone (same Wi-Fi). The laptop then does the heavy work (LMS, sheets, WhatsApp Desktop). When the laptop is off or away, the phone uses its own online brain.
   - **Laptop ke bina chalao:** add a free Groq key on the phone (stored encrypted in the Android Keystore).

### New in 0.7.0
- **Offline brain inside the installer** (Qwen3 0.6B with llama.cpp): no internet or no key? Rishu still answers: time, notes, reminders, opening apps, timetable, simple questions. It is slower and simpler than the online models; the bigger 1.7B model is an optional download (Settings → Offline dimaag).
- **Phone works by itself:** "Kal 6 baje ka alarm lagao", "10 minute ka timer", "YouTube pe Kesariya chalao", "WhatsApp kholo", "Shruti ko WhatsApp karo: aaj nahi aa paunga" (WhatsApp opens with the message typed; you press Send), "Papa ko call karo" (the dialer opens; you press call), web search, weather, "yaad rakho…". Calls and WhatsApp always show a card first.
- **Documents:** "Downloads wali PDF ka summary do", questions about Word, Excel and PowerPoint files.
- **Grading:** "Is folder ke assignments check karo, 10 mein se marks do" → marks with a reason for each student → after your "haan" they go into the Excel or Google Sheet.
- **Google Sheets:** give the sheet's link → "aaj ki attendance bharo: roll 5 absent, baaki present". Rishu works in its own browser window where you sign in to Google once, shows every row first, and checks the sheet after writing.
- **Tidy folders:** "Downloads saaf karo" → files sorted into Documents, Pictures, Videos… (nothing deleted; "undo karo" puts them back).
- **Dictation:** "Word mein likh do: …" types into the app you were using.
- **Good morning briefing:** today's classes, reminders, deadlines and weather in one answer.
- **Meeting notes:** "Meeting record karo" … "meeting khatam" → transcript (free Groq key) → notes with decisions and action items, as a Word file if you want.
- **Freelancing:** invoices with GST and the total in words ("Sharma Traders ke liye 15000 ka invoice"), deadlines with reminders, proposals as Word files. **LinkedIn:** Rishu drafts the post, copies it and opens LinkedIn's post box; you paste and post.

### Still works as before
Voice in Hindi, Hinglish and English; two styles (Professional / Personal); websites in Rishu's own browser; teach mode ("ek baar karke dikha do"); Lexyta attendance; Excel/CSV and register photos; WhatsApp Desktop; timetable and lecture reminders; Word notes and question papers; PIN / Windows Hello / spoken-password lock; permission cards, STOP, activity log.

### Known limits
- The offline brain is small: for LMS, sheets, research and grading use the online key.
- Spoken alerts for incoming WhatsApp messages are not possible for an unpackaged Windows app yet; entering marks inside Lexyta needs the gradebook pages (or teach it once).
- Needs a test on your devices: dictation and Google Sheets writing on a real desktop, phone alarms on your clock app.
